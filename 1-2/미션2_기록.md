# 미션 2 기록

- 사용한 AI 이름 / 주요 대화 캡처 파일명: 제미나이 3 / 오류이유찾기 / 찾은오류수정하기
- 좁혀서 적은 한 문장: 기획서와 HTML을 줄게. 직접 써 보니 기획서와 다르게 동작하는 곳이 있어. / 이 문제만 고쳐줘.다른 기능이나 화면은 그냥 둬. 외부 파일이나 서버없이 바로 열리는 수정한 html 전체를 줘.
- 좁히려고 해 본 것과 결과: 원하는데로 코딩되지 않은 이유를 확인하고 수정한 html을 확인. 
- AI가 말한 원인과, 그 설명을 직접 확인한 결과: html 속성의 한계로 확인됨. 띄어쓰기나 콜론이 프로그램인 thml 입장에서는 영화 제목 자체가 아니라 프로그램 언어처럼 인식되어 사용자가 원하는 방향으로 실행되지 않았음. ai에게 물어 이유와 결과를 확인하여 잘 알지 못했던 html의 맹점을 파악함.

| 파일명 | 고친 내용 | 다시 해 본 결과 |
|---|---|---|
| `영화_수정후.html` | 영화 카드 버튼을 동적으로 생성하는 자바스크립트 코드에서 `data-id` 속성값을 큰따옴표(`" "`)로 감싸도록 수정 (`data-id="${item.id}"`) | 제목에 콜론(`:`)이나 띄어쓰기가 포함된 **'센과 치히로의 행방불명', '어벤져스: 엔드게임', '토이 스토리'**를 포함한 모든 영화 카드가 S·A·B·C 및 미분류 칸으로 정상적으로 이동됨 |
